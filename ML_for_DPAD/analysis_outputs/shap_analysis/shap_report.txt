# DPAD Analysis - SHAP Interpretability Report
======================================================================

## Executive Summary

This report explains HOW the Random Forest model classifies calls
as High-DPAD vs Low-DPAD using SHAP (SHapley Additive exPlanations).

SHAP values show the contribution of each feature to each prediction:
- Positive SHAP: Feature pushes prediction toward High-DPAD
- Negative SHAP: Feature pushes prediction toward Low-DPAD
- Magnitude: How strong the push is

## 4. How to Interpret SHAP Plots

### Summary Plot
- **Y-axis**: Features ranked by importance
- **X-axis**: SHAP value (impact on prediction)
- **Color**: Feature value (red=high, blue=low)
- **Position**: Right of zero = pushes toward High-DPAD

### Dependence Plot
- **X-axis**: Feature value
- **Y-axis**: SHAP value for that feature
- **Color**: Value of interacting feature
- **Pattern**: Shows relationship and interactions

### Waterfall Plot
- Shows step-by-step how features combine
- Starts from base value (expected)
- Each bar adds/subtracts to reach final prediction
- Red bars push up, blue bars push down
