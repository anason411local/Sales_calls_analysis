## 5. How to Interpret LIME Explanations

**LIME Weight Interpretation:**
- Positive weight: Feature pushes prediction toward High-DPAD
- Negative weight: Feature pushes prediction toward Low-DPAD
- Larger magnitude: Stronger influence

**Feature Conditions:**
- LIME shows feature values as conditions (e.g., 'x <= 0.5')
- This indicates the feature value range for that prediction
- Multiple features combine linearly to reach final prediction
